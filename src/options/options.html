Agentic Skills Injector

Settings for the Firefox WebExtension

CDN Configuration

The base URL where skills/index.json and skills/*/SKILL.md are hosted. Must be a GitHub Pages URL (or custom domain pointing to Pages).

How long to cache the skill index before refreshing. Minimum 1 minute, maximum 24 hours.

Keyboard Shortcut

Alt+Shift+S Opens/closes the skills palette on supported sites

To change this shortcut, visit about:addons → Manage Extension Shortcuts → find "Agentic Skills Injector" → click the pencil icon next to "Open/close the Agentic Skills palette".

Supported Sites

  • Gemini: gemini.google.com
  • ChatGPT: chat.openai.com, chatgpt.com
  • Qwen: chat.qwen.ai, qwen.ai

The palette will only appear on these domains.

Privacy

This extension:

  • Does not collect any personal data or usage analytics
  • Stores only the skill index cache and your settings locally in browser.storage.local
  • Only makes network requests to the configured GitHub Pages CDN origin
  • Does not communicate with any other external services

See the Privacy Policy for full details.

How it works: Press Alt+Shift+S on a supported AI chat site to open the palette. Type /namespace:command to filter skills (e.g., /opsx:). Press Enter to copy the skill's markdown to your clipboard, then paste it into the chat input.
